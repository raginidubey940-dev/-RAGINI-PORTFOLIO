## ⚡ How to Run Locally

You do **not** need to install Node.js, npm, or heavy packages.

### Option 1: Instant Browser Open (Easiest)
Simply locate and **double-click `index.html`** in Windows File Explorer. It opens instantly in your default web browser (Chrome, Edge, Brave, etc.).

### Option 2: Local Python Server (Recommended)
Open PowerShell or Command Prompt in this folder and run:
```powershell
python -m http.server 3000
```
Then visit: `http://localhost:3000`

## 🛠️ How to Customize Your Details (Takes 2 Minutes)

All personal details are organized cleanly at the top of [`script.js`](file:///C:/Users/ragin/.gemini/antigravity/scratch/student-portfolio/script.js) and in [`index.html`](file:///C:/Users/ragin/.gemini/antigravity/scratch/student-portfolio/index.html):

### 1. Update Name & Email:
Open `script.js` and edit the first block:
```javascript
const PORTFOLIO_CONFIG = {
  studentName: "Your Full Name", // e.g. "Ragin Sharma"
  email: "your.name@jecrcu.edu.in", // your official email
  university: "JECRC University, Jaipur",
  degree: "B.Tech CSE (AI & ML) - 1st Year (2025-2029)"
};
```

### 2. Update Social Media Links:
In `index.html`, search for `social-icons-row` and paste your GitHub, LinkedIn, Kaggle, and Twitter/X handles.

## 🌐 How to Deploy Live for Free in 2 Minutes

### GitHub Pages (100% Free)
1. Create a free GitHub repository (e.g. `my-portfolio`).
2. Push or upload `index.html`, `styles.css`, `script.js`, and `README.md`.
3. Go to **Settings > Pages > Branch: main > Save**.
4. Your portfolio will be live at `https://yourusername.github.io/my-portfolio`!

### Vercel / Netlify
- Drag-and-drop this folder onto [netlify.com/drop](https://app.netlify.com/drop) or import your GitHub repo on [vercel.com](https://vercel.com).
